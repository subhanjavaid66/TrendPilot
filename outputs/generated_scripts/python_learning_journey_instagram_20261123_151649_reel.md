# Reel Script: Python learning journey (Instagram)

Hook (0-3s): “Python’s got a serious problem…”

Scene 1 | Visual: A tiny, pixelated Python character (Pip) frantically adjusting spaces, looking increasingly stressed. He’s surrounded by error messages floating around him. | Voiceover: “Pip was building a beautiful program, but he kept getting… errors!”

Scene 2 | Visual: Pip tries to add a line of code with a single space, then another, then a huge gap. The error messages multiply and start bouncing off him. | Voiceover: “See, in Python, it’s not *what* you write, it’s *where* you write it! Indentation is key.”

Scene 3 | Visual: Pip suddenly understands, and flawlessly adds the final line of code. The error messages disappear, and he beams. | Voiceover: “Consistent spacing tells Python exactly what to do. Now his program runs perfectly!”

Closing line: “Start your Python journey today – it’s all about the spaces!”
