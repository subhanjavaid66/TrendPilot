# Reel Script: Coding (LinkedIn)

Hook (0-3s): “Let’s be honest – coding can be frustrating.”

Scene 1 | Visual: Close-up shot of someone looking thoughtfully at a code editor, slightly furrowed brow. | Voiceover: "For me, it was always recursion. The concept of a function calling itself just… didn’t click."

Scene 2 | Visual: Screen recording showing a simple, clear example of a recursive function (e.g., calculating factorial). | Voiceover: "I overcame it by visualizing it – breaking down complex problems into smaller, self-similar steps. Drawing diagrams really helped."

Scene 3 | Visual: Shot of the same person now smiling confidently while typing code. | Voiceover: “It’s amazing how a single shift in perspective can unlock a whole new level of understanding. What was *your* coding hurdle?"

Closing line: “Share your biggest learning moment in the comments – let’s learn from each other.”
