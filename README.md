# TrendPilot

TrendPilot is a local Ollama-powered agent that turns a topic into platform-specific social content. It plans a workflow, generates content angles, writes and reviews a caption, creates hashtags, optionally creates a short-video script, and saves the result.

## Features

- Local LLM through Ollama; defaults to `gemma3:4b`.
- Inputs: topic, platform, tone, and output type.
- Tools: trend-idea generator, caption writer, hashtag generator, content analyzer, reviewer, reel-script generator, title/thumbnail generator, memory, and file saver.
- Streamlit interface and command-line interface.
- JSON history and saved Markdown/JSON results.
- Platform-specific word and hashtag scoring.

Trend ideas are generated by the local model; they are not verified real-time social-media trends.

## Setup

1. Install Python 3.10+ and [Ollama](https://ollama.com/).
2. Download the recommended model:

   ```powershell
   ollama pull gemma3:4b
   ```

3. Create and activate a virtual environment, then install dependencies:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

4. Copy `.env.example` to `.env` if you need to change the defaults. Do not commit `.env`.
5. Start Ollama and verify the model is available:

   ```powershell
   ollama run gemma3:4b
   ```

## Run the demo

Streamlit:

```powershell
streamlit run app.py
```

CLI:

```powershell
python main.py
```

The Streamlit app offers topic, platform, tone, and output-type controls, displays the analysis and review, and lets you download the full saved result. Generated files are written under `outputs/`; conversation history is stored in `memory/history.json`.

## Tests and evidence

Run the focused offline regression tests:

```powershell
python -m unittest test_content_analyzer test_main_output_types
```

Run the 10 Ollama-backed assignment scenarios (generation can take several minutes):

```powershell
python run_tests.py
```

The runner records prompts, tools, generated content, saved paths, scores, and output-contract checks in `tests/test_results.json` and `tests/test_cases.md`. Use `python run_tests.py 3 6 8` to run selected cases.
